# Dimanger

Проект собственного VPN-транспорта для macOS и Linux-сервера: защищённое соединение по TCP-порту 80 без TLS и X.509 в канале между VPN-клиентом и сервером.

**Состояние на 5 ноября 2026 года: архитектура и план реализации. Рабочий VPN, установщик и выпуск приложения пока не созданы.**

## Основные решения для рассмотрения

1. Собственное внешнее представление сообщений и управление соединениями Dimanger.
2. Проверяемая криптографическая основа: кандидат Noise IK с закреплённым открытым ключом сервера.
3. Одна входная служба на TCP:80, обслуживающая сайт и туннель.
4. Закрытые ключи создаются и остаются на соответствующих устройствах.
5. Мастер на Mac развёртывает Linux-сервер через проверенное SSH-соединение.
6. Нативный клиент macOS с системным сетевым расширением; подпись приложения отделена от защиты VPN-канала.
7. Сменяемые транспортные профили проходят отдельные испытания распознаваемости.
8. Заявления о полной нераспознаваемости не входят в гарантии проекта.

Папка самостоятельна относительно диагностики и BigSurVPN. Существующие команды установки этих проектов не устанавливают Dimanger.

## Граница обещаний

Отсутствие TLS в собственном туннеле не требует отключать HTTPS у посещаемых сайтов, подписи обновлений, проверку SSH-узла или защиту macOS. Бинарное соединение с портом 80 само по себе не является HTTP.

Репозиторий публичный. Секретность ключей обязательна; секретность устройства протокола не принимается как условие безопасности. Файлы реальных ключей, административные пароли, профили пользователей и захваты их трафика не являются материалами репозитория.
