# BigSurVPN 1.0.0

Консольный установщик и управление системным TUN для **установленной macOS Big Sur 11.x на Intel**. Не предназначен для Internet Recovery или Apple Silicon. Не требует Homebrew, App Store, Xcode и сторонних пакетов Python. Использует штатный Python 2.7; при его отсутствии останавливается.

## Установка

Встроенный персональный профиль зашифрован. Ключ установки выдаётся владельцу отдельно в чате и НЕ публикуется в этом репозитории. Не добавляйте ключ в issue, README, команды командной строки или историю shell.

Вставьте весь блок в Терминал:

```sh
(
  set -e
  D="$(mktemp -d)"
  trap 'rm -rf "$D"' EXIT
  curl -q -fL --proto '=https' --proto-redir '=https' \
    --proxy '' --noproxy '*' --connect-timeout 20 --max-time 180 --retry 2 \
    'https://raw.githubusercontent.com/pioner22/MacOS/eeb6613b53fcb88b0c6284a2b9d563f603552352/vpn-bigsur.sh' \
    -o "$D/vpn-bigsur.sh"
  printf '%s  %s\n' \
    '5e6cb6b63c4b120503eafdb625cc5e5e5dbb8e6f4cb639498fbc94ad73bb04c8' \
    "$D/vpn-bigsur.sh" | shasum -a 256 -c -
  /bin/bash "$D/vpn-bigsur.sh" install
)
```

Сначала может потребоваться пароль администратора Mac. На приглашение `Installation key from chat (hidden):` введите ключ из чата. Ввод не отображается. При повторной установке существующий локальный профиль сохраняется; для намеренной замены есть аргумент `install --reset-profile`.

Загрузка программы выполняется только с GitHub: raw.githubusercontent.com и официальный GitHub Release sing-box с перенаправлением на GitHub CDN. Доступность только главной страницы github.com недостаточна: нужен доступ к raw и release-assets CDN.

Установщик проверяет SHA-256 контроллера и ядра, затем запускает `sing-box version` на самом Mac. Установка сама по себе VPN не включает. Объём архива ядра — 26 335 501 байт.

## Управление

| Команда | Действие |
|---|---|
| `vpn-bigsur on` | Предварительная проверка сервера, затем запуск TUN и проверка системного маршрута |
| `vpn-bigsur off` | Штатная остановка службы |
| `vpn-bigsur status` | Процесс, маршрут, время последней успешной проверки; не новый тест связи |
| `vpn-bigsur test` | Проверка процесса, маршрутов IPv4/IPv6 и нового HTTPS-запроса через системный маршрут |
| `vpn-bigsur list` | Совместимые серверы подписки и резервные профили |
| `vpn-bigsur select 2` | Выбор приоритетного профиля номер 2; применится при следующем включении |
| `vpn-bigsur update` | Обновление подписки через уже включённый VPN без разрыва текущего соединения |
| `vpn-bigsur logs` | Журнал запуска; журнал каждого соединения отключён |
| `vpn-bigsur uninstall` | Остановка и удаление программы вместе с локальными профилями |

Когда команда не находится через PATH, используйте полный путь `/usr/local/bin/vpn-bigsur`. Для применения выбранного сервера: `vpn-bigsur off && vpn-bigsur on`.

## Первое подключение и подписка

Новая ссылка подписки встроена в зашифрованный профиль. Прямой доступ к ней из среды подготовки не удалось подтвердить; содержимое новой подписки не было прочитано.

Для первого подключения в зашифрованный профиль также включены два ранее предоставленных владельцем полных URI: Trojan TLS и VLESS REALITY. Это **резерв для первого подключения**, а не доказательство актуальности новой подписки. Их текущая работоспособность не проверена. Если провайдер отозвал оба ключа или изменил настройки серверов, первое подключение не состоится.

При `on` сначала выполняется HTTPS-запрос через локальный аутентифицированный прокси к выбранному серверу, БЕЗ изменения системных маршрутов. Этот прокси служит только для предварительной проверки. Если сервер доступен, запускается системный TUN `utun98`; проверяются маршруты IPv4 и IPv6, затем выполняется HTTPS-запрос без явного прокси. Сообщение об успешном включении появляется только после этих проверок.

После подключения новая подписка загружается через VPN и сохраняется локально. Импортированные профили применяются при следующем `on`; текущий сервер не переключается автоматически. Если обновление не удалось, работающее соединение сохраняется.

Поддерживаемый формат подписки: список URI или Base64 такого списка. Поддерживаются VLESS/Trojan с TLS, VLESS REALITY TCP, обычные TLS WebSocket/gRPC. Неизвестные параметры, неподдерживаемые протоколы и отключение TLS-проверки отклоняются; число пропущенных профилей выводится. HTML, произвольный JSON, xhttp и VMess этой версией конвертера не импортируются. Xray spiderX не переносится: для профиля REALITY успешность связи проверяется отдельно.

## Сеть и безопасность

Служба работает с root через launchd. Конфигурации и ключи после установки находятся в `/Library/BigSurVPN/private` с правами каталога 700 и файлов 600. Ссылка подписки и пароль прокси не передаются через argv и не печатаются в обычных сообщениях. Не публикуйте содержимое этого каталога.

В публичном установщике профиль защищён AES-256-CBC и HMAC-SHA256; используется случайный ключ высокой энтропии. HMAC проверяется до расшифровки. Ключ вводится один раз и не сохраняется. Шифрование публичной копии не заменяет защиту локального Mac: root имеет доступ к установленному профилю.

Ядро использует TUN, IPv4/IPv6-маршрутизацию и DNS-over-HTTPS через VPN. Имя самого VPN-сервера разрешается штатным DNS до запуска TUN; это предварительный прямой DNS-запрос. В конфигурации ядра нет direct-outbound для обхода VPN. Программа не изменяет SIP, Gatekeeper, проверку TLS, системные proxy-настройки или PF firewall. При обнаружении другого активного VPN-маршрута запуск отклоняется.

**Kill switch не установлен. При выключении или аварии ядра обычный прямой доступ в интернет возможен. Это не система гарантированной анонимности и не доказательство отсутствия всех утечек.** Автозапуск после перезагрузки намеренно не настроен. После перезагрузки требуется `vpn-bigsur on`. Закрытие окна Терминала после успешного `on` не является командой выключения: службой управляет launchd.

Проверки IPv6 подтверждают маршрут, а не фактическую передачу IPv6-данных. Проверка HTTPS не заменяет тест UDP, всех приложений, DNS-утечек, сна/пробуждения или смены Wi-Fi. Эти проверки должны выполняться на настоящем Mac.

## Проверки при подготовке

На Linux с Python 3 выполнены 32 автономных модульных теста: разбор URI/Base64, отказ от небезопасных профилей, формирование конфигурации, права файлов, безопасное извлечение архива, отсутствие изменения маршрутов при провале резервного подключения и вызов отката при моделируемом сбое запуска TUN. Все 32 прошли. Последние два теста используют mock, а не реальную сеть/launchd.

Дополнительно: синтаксис Bash, компиляция Python-кода, расшифровка правильным ключом, отказ при неправильном ключе и проверка отсутствия открытых персональных секретов в публикуемых файлах. Git blob SHA опубликованных контроллера и установщика совпали с локальными файлами.

**Не выполнены:** запуск Python 2.7 в Big Sur, запуск legacy-ядра на Mac, проверка конфигурации настоящим ядром в среде подготовки, установление соединения с сервером владельца, системный TUN/DNS на реальном Mac. Для этого установщик и команда `on` содержат проверки на целевом устройстве. Статус этих пунктов — НЕ ПРОВЕРЕНО, не PASS.

Запуск автономных тестов разработчиком в среде с Python 3:

```sh
python3 test_vpn_bigsur.py
bash -n vpn-bigsur.sh
```
