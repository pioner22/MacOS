# Архив прежнего клиента Yagodka

Этот Electron/web-клиент уже находился в репозитории до разделения диагностики и VPN. Он сохранён отдельно без удаления содержимого и не объявляется частью любого из двух приложений.

Каталоги `src/`, `public/`, `desktop/`, `scripts/`, `test/`, `build/` и файлы npm/Vite/Electron перенесены вместе с сохранением взаимных путей. Прежний общий README сохранён как `README.original.md`; его диагностический раздел относится теперь к `../../diagnostics/`.

Для работы именно с архивным клиентом сначала перейдите в эту папку. Его версии, зависимости, серверы обновлений и лицензионные материалы в рамках переноса не изменялись. Его сборка этим переносом не подтверждается.
