# rc8: результат пробы после тайм-аута

Дата: 2026-09-21. Это исправление программной проверки предварительных условий, а не результат аппаратной диагностики.

## Воспроизведённая ошибка

В rc7 `pf_probe` возвращал код дочерней команды. После истечения времени watchdog отправлял ей TERM. Если обработчик TERM завершал команду с кодом 0, `pf_read` принимал уже выведенное значение как достоверный факт. Аналогично могла подтверждаться возможность инструмента через `rg_probe`.

В регрессии настоящий процесс выводит `GenuineIntel`, ожидает сигнал и завершает его обработку с кодом 0. На rc7 результат: код 0 и принятый stdout. Отдельный исполняемый двойник `vm_stat` выдаёт правдоподобные показатели, затем превышает лимит; прежний `native_budget` принимает их и разрешает 8192 МиБ. Это воспроизведение ошибки программы с синтетическими данными, не измерение Mac и не запуск нагрузки такого объёма.

## Исправление

Watchdog фиксирует результат 124 **до** отправки TERM и сохраняет его при завершении через свой обработчик сигнала. Родитель получает этот результат через `wait` независимо от кода дочерней команды. Истечение лимита возвращает 124, даже если команда вернула 0. `pf_read` и `rg_probe` отклоняют такой stdout; расчёт бюджета памяти отказывает в запуске.

`probes.log` сохраняет эффективный `rc`, исходный `child_rc`, признак `timeout` и лимит. Пример: `rc=124 child_rc=0 timeout=1`. Обычный успешный вывод и обычные ошибки без тайм-аута сохраняют прежнюю семантику. Новых зависимостей целевой Recovery нет: используется имеющийся механизм Bash и watchdog.

## Проверки и выпуск

Добавлены девять регрессий с настоящими небольшими процессами: обработчик TERM с кодом 0, отбрасывание stdout, пробы реестра, штатное и игнорируемое завершение по TERM, журнал, обычный успех и ошибка, отказ бюджета при просроченном `vm_stat`. До исправления семь проверок падали, после исправления все девять прошли. Полный итог и воспроизводимые команды — в [RC8_QA.md](RC8_QA.md).

Версия комплекса — 2.0.0-rc8; загрузчик — 1.4; данные реестра — 2026-09-20.1. Постоянная команда остаётся:

```bash
curl -fL https://raw.githubusercontent.com/pioner22/MacOS/main/st.sh | bash
```

Порядок запуска, меню, обязательный mlock, учёт покрытия, согласие на запись и блокировка RAW сохраняются. Сетевые и программные ограничения не превращаются в аппаратный дефект.

## Границы результата

Регрессии выполнялись на Linux. Настоящие Recovery, Bash 3.2, Apple clang, Metal и нагрузки 40–48 ГиБ этим этапом не подтверждены. Проверенные готовые нативные Recovery-бинарники ещё не поставляются. Механизм тайм-аута не гарантирует немедленного завершения зависшего ядра или драйвера. Этот этап проверяет сохранение факта тайм-аута, а не полную изоляцию всех возможных деревьев процессов системных утилит.
