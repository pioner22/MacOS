# Catalina через VLESS на втором Intel Mac — 1.1.1

`download-vpn.sh` предназначен для A1398 с обычной macOS Big Sur, **не для Recovery на A2141**. Старые `proxy.sh` и `vless.sh` одновременно не запускать. Используется VLESS + REALITY + XTLS Vision, а не прежнее SSH-подключение.

## Встроенная ссылка

По прямому запросу владельца в существующий скрипт добавлена его ссылка подписки как `DEFAULT_SUBSCRIPTION`. Обычный запуск больше не требует ввода ссылки. Этот preset имеет приоритет над ранее сохранённым профилем. При нескольких поддерживаемых записях остаётся выбор номера сервера.

**ВНИМАНИЕ: этот репозиторий публичный. Встроенная ссылка содержит данные доступа к подписке и теперь доступна читателям репозитория и истории коммитов. После восстановления отзовите эту ссылку у VPN-провайдера. Удаление строки из текущей версии не отзывает доступ и не удаляет её из старого коммита. Не используйте эту версию как образец хранения постоянных секретов.**

## Короткий запуск

На A1398, без sudo, после завершения или остановки предыдущего запуска:

```bash
curl -qfLo ~/v.sh https://raw.githubusercontent.com/pioner22/MacOS/rescue/download-vpn.sh && bash ~/v.sh
```

**Для использования встроенной ссылки не добавляйте `--reconfigure`: этот параметр специально возвращает ручной запрос.**

Повторный запуск:

```bash
bash ~/v.sh
```

Явный локальный файл с другой ссылкой имеет приоритет над встроенной:

```bash
bash ~/v.sh --uri-file "$HOME/Downloads/vpn-link.txt"
```

Файл должен содержать одну строку vless:// или HTTPS-ссылку подписки. Не передавайте секретную ссылку аргументом командной строки и не выполняйте содержимое подписки через bash.

## Импорт и проверки

Поддерживаются HTTPS-подписки, возвращающие обычный список URI либо Base64-кодированный список (стандартный или URL-safe). Допускаются CRLF, UTF-8 BOM и отсутствие завершающего Base64 padding. HTML, JSON/Xray и YAML/Clash конфигурации не импортируются.

Из списка выбираются только VLESS / REALITY / xtls-rprx-vision / TCP / encryption=none / fp=chrome. Один подходящий профиль выбирается автоматически. При нескольких выводится нумерованный список серверов без UUID и произвольных названий. Для явного выбора доступен `--profile-index N`. Другие протоколы и транспорты не преобразуются. Параметр spx/spiderX не переносится в выдуманное поле sing-box; совместимость подтверждается только реальным соединением.

Подписка получается через обычную сеть до включения VLESS. TLS проверяется, автоматические перенаправления отключены. URL передаётся curl через stdin-конфигурацию, не через аргументы процесса. При 301/302/403, HTML или неподдерживаемом формате программа останавливается. Ограничения: 60 секунд, до 1 МиБ ответа, до 128 записей. Это не проверка доступности подписки заранее: фактический результат появляется на компьютере пользователя.

Исходная ссылка сохраняется локально в `~/macOS-rescue/.vless-client/profile.uri`, права 600, каталог 700. Это права доступа, не шифрование; встроенная ссылка при этом уже публична. JSON и ответы подписки могут содержать дополнительные секреты. Каталог `.vless-client` целиком не публикуйте. Тела ответов подписки удаляются при штатном завершении или обработанном сигнале; аварийное выключение может оставить их на диске.

## Подключение и загрузка

Скрипт получает официальный sing-box 1.14.0 `darwin-amd64-legacy-macos-10.13` (около 26 МБ), сверяет закреплённый SHA-256, затем запускает `version` и `check`. Загрузчик `download-catalina.sh` 1.1.0 получается по закреплённому коммиту и тоже проверяется по SHA-256. Никаких обновлений Homebrew/Python/macOS нет.

Клиент слушает только localhost на свободном порту 2080–2090. **Это не VPN всего компьютера:** маршруты, DNS, hosts и системные прокси не меняются; TUN, firewall, launchd и sudo не используются. Через VLESS направляются проверочный запрос и HEAD/GET загрузчика. При отказе прокси прямого fallback для них нет. Подписка, GitHub и разрешение адреса VLESS-сервера используют обычную сеть. Системные проверки доверия после загрузки не получают гарантию маршрутизации через этот прокси.

Если GitHub недоступен, архив клиента можно перенести с другого устройства и передать через `--core-archive /абсолютный/путь/архив.tar.gz`. Проверка SHA-256 остаётся обязательной. Доступ к raw.githubusercontent.com для закреплённого загрузчика всё равно нужен. Не отключайте сертификатные проверки или проверку хеша.

После успешного HEAD к www.apple.com начинается загрузка `InstallESDDmg.pkg` продукта 001-68446. Используется HTTPS-вариант пути из журнала: успех не доказывает исправность исходного HTTP-запроса Recovery.

Ожидаемые этапы, не заранее подтверждённые результаты:

```text
CATALINA VIA VLESS 1.1.1
Using the configured subscription; no link entry is required.
SUBSCRIPTION_FETCH: curl=0 HTTP=200
...
VLESS_TEST_OK: ...
TRANSPORT=SOCKS5H ENDPOINT=127.0.0.1:2080 DIRECT_FALLBACK=DISABLED
HEAD_CURL_EXIT=0
...
DOWNLOAD_OK: ...
READY_FOR_REVIEW: ...
DOWNLOADER_EXIT=0
```

Порт и число профилей могут отличаться. Проверка сайта не подтверждает доступность всего пакета.

## Файлы, продолжение и остановка

Результаты: `~/macOS-rescue/Catalina-001-68446-VLESS/`. До завершения передачи файл оканчивается на `.part`; предыдущая прямая загрузка не удаляется и не импортируется. В одном запуске не больше трёх GET-попыток; дозагрузка разрешена при согласованных Range и ETag/Last-Modified. Ограничение одной попытки — два часа; 120 секунд со скоростью менее 1 КиБ/с останавливают запрос. Ошибки сертификатов, изменившиеся данные и аварии не обходятся. Для независимой попытки можно указать `--output /абсолютный/путь`.

После передачи проверяются размер, собственный SHA-256 и фактический формат. Для XAR/PKG используется `pkgutil --check-signature`, для UDIF/DMG — `hdiutil verify`. Пакет не исполняется, образ не монтируется. `READY_FOR_REVIEW` означает успех предусмотренных команд, не гарантию установки. Собственный SHA-256 без доверенного эталона не доказывает подлинность; проверка DMG не проверяет все внутренние подписи и отзыв сертификатов. Этот скрипт не поднимает локальное зеркало и не создаёт флешку.

Питание A1398 подключить, Терминал и крышку оставить открытыми. `caffeinate` предотвращает автоматический сон на время запуска. Ctrl+C останавливает работу, частичный пакет сохраняется. Своему клиенту отправляется TERM; принудительный SIGKILL не используется. Постоянного демона, автозапуска и защиты от аппаратного зависания нет.
