# TUI VPN

Терминальный VPN-клиент с постоянной службой, подписками, графиками входящего
и исходящего трафика, автоматическим выбором и ручным переключением серверов.

Первый выпуск: **macOS 11 Big Sur Intel**, **Ubuntu 22.04+ / Debian 12+**
на amd64 и arm64. Apple Silicon в этом выпуске macOS не поддерживается.

## Установка

Установщики находятся в [dist](dist/), SHA-256 — в [dist/SHA256SUMS](dist/SHA256SUMS).

- Mac: откройте `TUI_VPN-0.1.0-macos-intel.pkg` системным установщиком.
- Ubuntu/Debian: установите `tui-vpn_0.1.0_all.deb` через штатный менеджер
  пакетов. Он должен разрешить зависимости Python 3, curl, iproute2,
  nftables и сертификатов CA.

Нужны права администратора и интернет: пакет скачивает соответствующее ядро
и, на Mac, отдельный Python. Архивы закреплены SHA-256; система Python и
Homebrew на Mac не меняются. Это онлайн-установщик, не автономный архив.
Mac-пакет не подписан Developer ID и не нотарифицирован. Используйте
обычный механизм разрешения открытия доверенного пакета macOS; отключать
Gatekeeper, SIP или антивирус не требуется.

После установки запустите **TUI_VPN.command** в `/Applications` на Mac,
**TUI VPN** в меню приложений Linux либо команду `tui-vpn`.
Сначала VPN выключен. Установка не импортирует чужие ключи и не включает
туннель поверх действующего VPN.

На Linux владелец управления берётся из `SUDO_UID`, `PKEXEC_UID` или активной локальной сессии. Если пакет
установлен на headless-системе без определимого пользователя, интерфейс также
запускается root. На Mac управление получает пользователь активной консоли.

## Интерфейс

- `1` — обзор, реальные RX/TX и графики; `2` — серверы; `3` — подписки;
  `4` — ограниченный журнал без посещённых сайтов и реквизитов.
- `Space` — включить/выключить; `A` — автоматический режим; `Enter` на
  сервере — ручной выбор. В ручном режиме автоматическое переключение
  отключено до нажатия `A`.
- На вкладке подписок: `N` — HTTPS-ссылка; `I` — URI; `W` — собственный
  обычный WireGuard `.conf`; `E` — изменить ссылку; `R` — обновить выбранную подписку;
  `D` — удалить с подтверждением. `L` на Mac импортирует существующий
  BigSurVPN по явному действию пользователя.
- `T` — тема ocean/light/mono; `U` — проверка обновления программы;
  `Q` — закрыть TUI. Закрытие окна не выключает VPN.

Ссылки и URI вводятся скрыто, не через аргументы оболочки. Поддерживаются
обычные VLESS/Trojan TLS URI, SOCKS5 URI, base64/text-подписки, sing-box JSON
с поддерживаемыми outbounds и обычный WireGuard. Proprietary Happ encrypted
links, XHTTP и AmneziaWG не преобразуются догадками. Для них нужен совместимый
экспорт. Неверное обновление сохраняет прежнюю подписку.

## Постоянная работа и диагностика

`tui-vpn on`, `off`, `status`, `test`, `logs`, `auto`, `doctor` работают
через закрытый локальный сокет. Обычное управление не запускает произвольных
команд от root. Служба запускается через launchd/systemd после загрузки.
Ручное OFF сохраняется на диске и не отменяется автоматикой.

После ON возможен статус «запуск», затем «онлайн» после HTTPS-проверки.
Автовыбор использует native URLTest с интервалом 15 секунд. Обнаружение отказа
зависит также от сетевых тайм-аутов. Старые TCP-сессии не переносятся между
серверами. SOCKS5 обслуживает TCP; в автоматическом режиме UDP выбирается из
поддерживающих его транспортов. SOCKS5 сам по себе не шифрует канал: защита
содержимого зависит от TLS приложений. Прямого резервного выхода для пользовательского трафика нет.

Это не системный kill switch: при аварии всего ядра ОС может снять маршруты
туннеля до его восстановления. Клиент не обещает обход любой блокировки DPI.
Счётчики относятся к текущему сеансу ядра и включают служебные проверки.
Неудавшееся измерение показывается как отсутствие данных, а не успех.

`tui-vpn test` дополнительно проверяет системный маршрут и свежий HTTPS.
«Процесс запущен» не равнозначно работающему интернету.

## Обновление, откат, удаление

`U` или `tui-vpn update` проверяет метаданные в этой же GitHub-папке на
конкретном commit, сверяет версию, срок метаданных, размер и SHA-256 пакета.
Только после выбора пользователя запускается системный установщик.
Источник доверия обновления — HTTPS и доступ издателя к `pioner22/MacOS`.

Данные вне релизов: Mac — закрытый `private` в
`/Library/Application Support/TUI_VPN`; Linux — `/var/lib/tui-vpn`.
Обновление не восстанавливает старую копию подписок поверх новых данных.
Код переключается через `current`; предыдущий выпуск доступен для отката.
Неизвестные изменения файлов блокируют автоматическую замену.

`tui-vpn rollback` возвращает предыдущий выпуск программы после системной
авторизации. `tui-vpn uninstall` выключает службу и удаляет её точки запуска;
профили, ключи и материалы восстановления сохраняются. Для .deb штатное
удаление пакета выполняет ту же деактивацию. Повторная установка использует
сохранённое ручное OFF. Пользовательские данные автоматически не стираются.

## Разработка

Исходники: `src/`; настройки: `config/`; упаковка: `packaging/`; тесты: `tests/`;
документация: `docs/`. `build_packages.py` создаёт манифест и установщики.
Для macOS-сборки нужен системный `pkgbuild`; .deb собирается стандартной
библиотекой Python. `--linux-only` не требует Mac.

Демо не создаёт туннель: `python3 src/entry.py --demo`. В нём трафик явно
помечен как синтетический. Реальные реквизиты и профили не входят в исходники,
демо, тесты, установщики и GitHub. Границы фактически выполненных проверок
указаны в [docs/VALIDATION.md](https://github.com/pioner22/MacOS/blob/main/TUI_VPN/docs/VALIDATION.md).
