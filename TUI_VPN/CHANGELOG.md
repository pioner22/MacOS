# История изменений

## 0.1.2

- Обычная ссылка подписки загружает поддерживаемые профили; повторный импорт обновляет её, переносы строк Base64 допустимы. Неизменившееся обновление не перезапускает соединение.
- Добавлено окно SOCKS5: создание, редактирование и удаление, скрытый пароль, сохранение пароля при пустом поле редактирования.
- Общий список показывает источник, протокол, результат HTTPS-проверки, задержку и свежесть. Проверки используют отдельное штатное ядро без TUN; число процессов, запросов и время ограничены.
- Ручное OFF отменяет проверки и незавершённый откат каталога. Запоздалый запрос включения не отменяет более новое выключение. Другой активный VPN проверяется до сохранения ON.
- Колесо и нажатие мыши без отпускания не активируют кнопки. Ошибки импорта не показывают содержимое подписки. Небезопасный параметр netns отклоняется.
- Схема SQLite остаётся 1; прежние данные и откат к 0.1.1 совместимы. Ядро и зависимости не менялись.

## 0.1.1

- Исправлено падение TUI при изменении размера окна на Big Sur: закреплён совместимый модуль CPython `_curses`; системные библиотеки не меняются.
- Среда Python и ссылки версии становятся доступны обычному пользователю после установки; закрытые данные сохраняют права 0700/0600.
- На Mac интерфейс запускается без sudo, чтобы настройки темы не переходили к root.
- Перезапуск launchd ждёт завершения прежнего процесса. Неопределённый ответ bootstrap проверяется перед повтором; откат подтверждает восстановление контроллера.
- При запрошенном включении установка дополнительно проверяет рабочие маршруты и HTTPS; выключенное состояние проверяется без включения туннеля.
- Формат подписок, схема данных, сетевое ядро и службы прежние. Обновление сохраняет профили и запрошенное включение/выключение.

## 0.1.0

- Первая самостоятельная поставка для Big Sur Intel и Ubuntu/Debian.
- Curses TUI, подписки, RX/TX, журнал, native URLTest и ручной selector.
- Пакеты .pkg/.deb с проверкой закреплённых зависимостей.
- Постоянное ручное выключение, отдельные приватные данные и откат кода.
- Новая служба не заменяет и не перезапускает прежний BigSurVPN автоматически.
