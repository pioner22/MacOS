# Архитектура и границы

Владелец кода: pioner22. Владелец эксплуатации — администратор устанавливаемого
компьютера. Общая кодовая база Python 3.8+, терминальный интерфейс curses.

Интерфейс непривилегированный. Служба root принимает ограниченный JSON RPC
по Unix socket: только владелец установки и root, нативная проверка peer UID,
предел сообщения, тайм-аут и не более восьми одновременных обработчиков.
RPC не содержит запуска shell, произвольных путей файлов или скачивания кода.
WireGuard-файл читает интерфейс с правами пользователя и передаёт только
данные. URL подписки обрабатывает отдельный ограниченный HTTPS-worker.

Root хранит каталог и флаг OFF в закрытой SQLite-базе отдельно от неизменяемых выпусков.
Изменение каталога и состояния атомарно: обе записи входят в одну транзакцию. Native
sing-box реализует транспорт, selector, URLTest, счётчики и маршрутизацию.
Контроллер обслуживает состояние, импорт, ACL и жизненный цикл процесса.
macOS DNS — временная сессия SystemConfiguration, Linux DNS/TUN — штатный
auto_route/auto_redirect/hijack ядра. Постоянные resolv.conf и настройки
интерфейсов вручную не переписываются.

Контроль API ядра доступен только на loopback со случайным секретом. TUI
получает суммарные счётчики и состояние, но не список сайтов, токены API,
исходные URL подписок или пароли. Рабочие файлы root — 0600, private — 0700.

Пределы: 20 подписок, суммарно 200 серверов, подписка до 2 МиБ, RPC до
128 КиБ, ответ до 1 МиБ, журнал 100 событий, график 80 отсчётов. Поллинг
интерфейса раз в секунду; URLTest раз в 15 секунд. Ни один источник не
является кодом: hooks WireGuard, file paths и системные dial options
из внешних конфигураций отклоняются.

Суммарный JSON-каталог ограничен 4 МиБ до записи, тем же пределом, что чтение
после перезапуска. Изменение профиля сбрасывает его оценку доступности.
Одинаковый адрес с разными реквизитами остаётся разными подключениями.

Модули manual_profiles и ui_forms обслуживают ручной SOCKS5 и поля формы.
health_checks запускает один ограниченный helper из установленного выпуска;
probe_runtime использует штатный Clash API sing-box /proxies/.../delay.
Этот процесс не создаёт TUN, не меняет DNS и не имеет входов для трафика.
API слушает только loopback со случайным секретом. Результат привязан
к поколению запроса и полным реквизитам профиля; поздний ответ отменённой
проверки игнорируется. Возраст учитывает сон компьютера.

Пределы проверки задаются в defaults.json: четыре параллельных запроса,
6 секунд на профиль, 180 секунд на пакет, 60 секунд свежести, 5 секунд
между запусками. Имена серверов разрешаются один раз; ядру передаются
закреплённые IP с сохранением TLS server_name. Внешняя подписка не может
проверять частные адреса; явно добавленный локальный SOCKS5 может.
Link-local, multicast и неопределённые адреса запрещены в обоих случаях.
По возможности исходящий запрос привязан к физическому интерфейсу;
интерфейс показывает фактический выбранный контекст проверки.

Отказы: процесс ядра повторяется с задержкой 2–30 секунд только при ON;
ошибка подписки сохраняет текущие узлы; неудачный системный запуск нового
выпуска возвращает точные старые файлы и ссылку current. Каталог подписок
не откатывается пакетом программы. Повреждённый флаг состояния не включает
VPN по умолчанию. Другой активный туннель блокирует запуск, его маршруты
не удаляются. Закрытие TUI не прекращает работу службы.

Выбраны стандартные curses, launchd/systemd и native sing-box API.
Textual/Qt/Electron и отдельный сетевой движок не добавлялись: для этих
пользовательских сценариев они увеличивали бы размер и число зависимостей.
Проверка подписи Developer ID недоступна без сертификата издателя; её
отсутствие прямо указано. Проверки целостности не называются подписью.
