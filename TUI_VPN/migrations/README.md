# Версия данных 1

Первый выпуск создаёт закрытую SQLite-базу с PRAGMA user_version=1.
Каталог, предыдущий каталог и желаемое состояние хранятся как три JSON-документа.
Изменение каталога и переключателя выполняется одной транзакцией.
Будущая несовместимая схема требует отдельной миграции, SQLite backup и проверки
обратной совместимости. Откат кода не заменяет текущую базу старым снимком.
BigSurVPN импортируется только явным действием пользователя и сохраняет свои файлы.

0.1.2 сохраняет версию данных 1. Ручные SOCKS5 используют прежние локальные
источники; пароль остаётся только в закрытой базе. Проверки доступности
хранятся в памяти, не требуют миграции и сбрасываются после перезапуска.
RPC v1 расширен командами probe, socks_details, socks_save и server_delete;
прежние команды совместимы. Откат программы к 0.1.1 сохраняет добавленные
подключения, но убирает новое окно SOCKS5 и проверки до подключения.
