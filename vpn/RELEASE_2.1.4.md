# BigSurVPN CLI 2.1.4

## Установка и запуск мастера

Один раз обновить установленную 2.1.3 через постоянный загрузчик:

```sh
curl -fL https://raw.githubusercontent.com/pioner22/MacOS/main/vpn.sh | bash
vpn-bigsur --version
```

После обновления мастер открывается локально, без повторного скачивания программы:

```sh
vpn-bigsur wizard
# Равнозначная команда:
vpn-bigsur menu
```

Меню: 1 — Xray/VLESS/Trojan; 2 — SOCKS5; 0 — отмена. Мастер использует сохранённые
профили, проверяет целостность установленной программы, запрашивает административные
права через прежнюю оболочку, переподключает и проверяет соединение. Ядро и установщик
не скачиваются. Отмена выбора не выключает работающий VPN.

## Два адреса SOCKS5

В публичный временный профиль владельца добавлен 87.251.86.229. Основной адрес
144.31.180.114 сохранён. Оба используют порт 45004 и прежние реквизиты.

При установке, запуске мастера или новом подключении адреса проверяются по порядку:
первый проходит SOCKS5-аутентификацию и HTTPS-проверку — используется он; при отказе
проверяется второй. Если ни один не прошёл, новый туннель не запускается. Открытый порт
или ICMP-ответ не подменяет проверку. После запуска TUN отдельно проверяются служба,
маршруты, DNS, HTTPS и выходной IP. Неуспешная итоговая проверка запускает очистку,
а не ложное сообщение о готовности.

```sh
vpn-bigsur list       # адреса выбранного режима, без паролей
vpn-bigsur select 2   # сделать второй адрес приоритетным; пока не переподключает
vpn-bigsur wizard    # применить выбор, в меню выбрать SOCKS5
vpn-bigsur status    # последний подключённый адрес и состояние
```

Приоритет не запрещает пробовать другой адрес. Выходной IP сервера с несколькими
адресами не обязан совпадать с адресом подключения. Старые профили с одним адресом
остаются допустимыми; данные Xray не заменяются SOCKS5-профилями.

## Проверки и границы

129 целевых тестов прошли на Linux: 43 новых проверки нескольких адресов/мастера,
65 прежних проверок SOCKS5 и 21 проверка доставки. Для нового поведения обновлено
ожидание сохранения SOCKS5-приоритета в прежнем тесте; для перенесённых файлов — URL
в тесте загрузчика. Реальные временные файлы, права и shell-процессы; сеть, sing-box,
launchd и маршрутизация в тестах жизненного цикла подменены. Это не запуск на Big Sur,
не проверка доступности обоих серверов и не успешный GitHub Actions.

Проверены SHA-256 runtime/профиля и оба уровня закреплённых загрузчиков. Изменения
касаются CLI; незавершённое графическое приложение из PR #19 не публикуется.

Автоматического мониторинга обрывов каждые 2 секунды в этом выпуске нет. Запущенный
`on` проверяет существующее соединение; новый перебор выполняется при переподключении.
`update` по-прежнему обновляет подписку, не программу. У SOCKS5 подписки нет.

При переподключении возможен прямой интернет: kill switch не добавлен. Если мастер
не смог подключиться, сохраняется прежний выбор профиля, но восстановление прежнего
туннеля не обещается; проверить `status`, затем `on`. Ctrl+C не запускает новые попытки.
SOCKS5-транспорт и его пароль не шифруются. Дополнительные IP одного сервера не
защищают от отказа самого сервера. Временные публичные реквизиты следует отзывать
на сервере; удаления файла из Git недостаточно.
