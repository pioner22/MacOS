# BigSurVPN 2.1.3: групповые права каталога команд

## Наблюдение и воспроизведение

На последнем снимке пользователя загрузчик 2.1.2 успешно проверяет оба скачанных файла, затем сообщает: «Небезопасный тип или права каталога команды: /usr/local/bin». Это уже не старый отказ по владельцу и не ошибка контрольной суммы. Фотография не показывает фактические mode/uid/gid и не доказывает, что на Mac именно 0775: прежняя ошибка объединяла неверный тип, групповую запись и запись для остальных.

Фактический опубликованный runtime с Git blob `409089430e037f5f8408c56e54a63193a626897c` проверял `st_mode & 0022`. На реальном временном каталоге с режимом 0775 этот код воспроизвёл ту же ошибку. Исправленный runtime принял каталог, оставив режим 0775 и владельца без изменений.

## Изменения

Проверка общих `/usr/local` и `/usr/local/bin` отделена от проверки привилегированных файлов. Они содержат только ссылку для запуска обычным пользователем. Групповая запись допускается; в тестах проверены 0775, 02775 и 01775 при root- и user-владельцах. Запись для остальных, символические ссылки, обычные файлы/FIFO вместо каталога и отсутствие прохода по-прежнему отклоняются. Ошибка теперь сообщает фактический тип, uid, gid и mode, а не объединяет причины без деталей.

Установщик не делает chown этих каталогов и не меняет имеющиеся групповые режимы. Сохраняется прежнее исправление созданных каталогов и root-каталогов 0700, полученных из-за umask 077. Проверки `/Library/BigSurVPN`, закрытых конфигураций, релизов и root-оболочки НЕ ослаблены. `sudo` и launchd используют защищённые абсолютные пути, а не `/usr/local/bin/vpn-bigsur` для запуска привилегированного кода. Как и любой общий PATH-каталог, место размещения ссылки требует доверия к пользователям, которые могут заменить эту ссылку; это не гарантия защиты от них.

Из существующих функций изменена только `prepare_command_dir`; добавлена `command_path_details`. Синтаксические деревья 72 других функций/классов совпали с исходной версией. Сетевые операции, выбор Xray/SOCKS5, конфигурация ядра и профиль провайдера не менялись.

Версии runtime, оболочки, отчётов и загрузчика согласованы: 2.1.3. Внутренние runtime_ref/runtime_sha загрузчика обновлены на реально опубликованные и проверенные байты, а закрепление профиля оставлено прежним. Пользовательский адрес остаётся:

```sh
curl -fL https://raw.githubusercontent.com/pioner22/MacOS/main/vpn.sh | bash
```

Для резерва в меню выбрать 2. Пересоздание соединения может временно открыть прямой интернет, как и в предыдущей версии.

## Проверки

Выполнено **111 из 111 целевых тестов, без пропусков**: 52 существующие проверки прав/CLI, 19 существующих проверок доставки и 40 новых проверок общих каталогов/меню/доставки. Среда: Linux x86_64, Python 3.13.5, Bash среды выполнения; root и реальные непривилегированные дочерние процессы. Все пути тестов находятся во временных каталогах. Реальные `/Library` и `/usr/local` тестами не меняются.

Важные сценарии: реальная проверка каталога 0775 до и после исправления; сохранение владельца, группы, режима и inode; повторное применение; безопасное создание отсутствующего bin при umask 077; отсутствие ослабления закрытых каталогов; вызов публичной оболочки непривилегированным пользователем; отказ в чтении приватного файла; прохождение реального preflight до меню при 0775 и отмена без сетевых действий; совпадение версии и SHA-256 загрузчика; выполнение только проверенных байтов после повышения прав; отказ при подмене/усечении/неверной сумме.

Для воспроизведения именно этого целевого набора из репозитория:

```sh
python3 -m unittest discover -s tests -p 'test_vpn_permissions_cli.py' -v
python3 -m unittest discover -s tests -p 'test_vpn_bootstrap_delivery.py' -v
python3 -m unittest discover -s tests -p 'test_vpn_shared_command_dir.py' -v
```

Опубликованные runtime, загрузчик и новый файл тестов совпали по Git blob с локальными тестируемыми копиями. SHA-256 runtime вычислен локально, а не подобран или переписан вручную без вычисления. Runtime: 81635 байт. Blob `608cd3b5d187849b5496c938ae8d647483085ca5`, SHA-256 `966a6d63a7968113af5c713b5595c9c9c53628fb80e83badd31bedb84d24b877`. Загрузчик ссылается на коммит runtime `56256fcd2b279fb4bbcef1b2be4a2366ce6fd7de`.

Это **не полный прогон всего репозитория и не подтверждение работы VPN на Mac**. macOS Big Sur, её Python 2.7/Bash 3.2, ACL, реальные launchd/TUN/DNS и подключение к резерву в этой среде не проверены. Успех тестов не устанавливает фактические права каталога на устройстве пользователя. Если там ссылка либо запись для всех, новая версия даст конкретную диагностику, а не молча изменит систему.
