# BigSurVPN

## CLI: действующая версия 2.1.4

`vpn.sh` — установщик; `vpn-runtime.py` — управляющий runtime; `vpn-profile.json` — данные поставки.
`tests/` и `test_vpn_*.py` — существующие программные тесты. Документация сохранена в `VPN_*.md`.
`vpn-bigsur.py` и `vpn-bigsur.sh` — прежняя реализация; для обычной установки используйте постоянную ссылку ниже.

```sh
curl -fL https://raw.githubusercontent.com/pioner22/MacOS/main/vpn.sh | bash
```

Скрипт рассчитан на установленную Big Sur 11.x Intel, не Recovery.
В CLI 2.1.4 `vpn-bigsur update` обновляет только подписку. Для обновления программы используется установщик; подключение может быть пересоздано.

После установки мастер выбора Xray/SOCKS5 запускается без ссылки:

```sh
vpn-bigsur wizard
# или: vpn-bigsur menu
vpn-bigsur list
vpn-bigsur status
```

В SOCKS5-профиле проверяются адреса 144.31.180.114 и 87.251.86.229, порт 45004, прежняя авторизация. Используется первый адрес, прошедший проверку подключения и HTTPS. `select N` задаёт приоритет, но не запрещает проверку других адресов. [Подробности версии 2.1.4](RELEASE_2.1.4.md).
Постоянного мониторинга обрывов и kill switch этот выпуск не добавляет.

## Нативное приложение

Исходники разрабатываемого приложения находятся в `vpn/app/` ветки `feat/bigsurvpn-app-signed-updates`, [PR #19](https://github.com/pioner22/MacOS/pull/19).
В основной ветке этот каталог служит указателем, а не обещанием готового приложения. Этот выпуск CLI не сливает незавершённый PR и не публикует `.app`.

## Проверки из папки vpn

```sh
python3 -B -m unittest discover -s tests -p 'test_vpn_*.py' -v
python3 -B test_vpn_compat.py
```

Часть проверок владельцев требует root в изолированной тестовой среде. Не запускайте аппаратные или привилегированные тесты на рабочем Mac только ради перестройки папок.
Канонические пути внутри этой папки сохранены, поэтому взаимное расположение runtime, установщика и тестов не изменилось.

## Данные подключения

Файл поставки содержит ранее опубликованные временные VPN-реквизиты по решению владельца. Перенос не делает их секретными. Не добавляйте сюда новые закрытые ключи; для прекращения доступа временные реквизиты нужно отзывать на сервере.
