# BigSurVPN 2.0.3: одна команда установки и управления

Дата: 21 сентября 2026 года. Это исправление прав и поведения установщика, не полный аудит VPN и не подтверждение работы на конкретном Mac.

## Постоянная команда

После слияния PR №12 в main:

```sh
curl -fL https://raw.githubusercontent.com/pioner22/MacOS/main/vpn.sh | bash
```

Адрес для пользователя не содержит номера коммита или версии. При каждой публикации обновляется загрузчик в main; проверка целостности и закрепление компонентов остаются внутри. `macdiag-core.sh` — отдельная диагностика, не установщик VPN; его назначение не меняется.

При первой установке команда устанавливает программу, создаёт конфигурацию, запускает собственную службу и выполняет проверки. При повторном запуске она обновляет программу при отличии кода/профиля и пересоздаёт подключение даже при совпадении версии. Если файлы уже актуальны и проверены, повторная загрузка ядра не нужна. Старая активная сессия больше не используется вместо нового подключения: выполняются stop, новый исходный замер, connect и итоговая проверка. Подписка обновляется при подключении; при её недоступности используются совместимые сохранённые или резервные профили, если они проходят проверку.

Предварительные проверки путей и проверка скачанных компонентов при обновлении выполняются до остановки собственной старой службы. Ошибки предварительной проверки не выдаются за успешное обновление. После остановки возможен прямой интернет; если дальнейший этап не удался, восстановление прежнего работающего туннеля не гарантируется. Автоматическая блокировка трафика при отсутствии туннеля (kill switch) и автозапуск после перезагрузки не добавлены.

## Исправление прав

`umask 077` превращал `mkdir(..., 0755)` в `0700`, закрывая команду обычному пользователю. Теперь после проверки владельцев, типов и приватного состояния явно задаются:

- `/Library/BigSurVPN`: 0755;
- `releases`: 0755;
- `private`: 0700;
- оболочка команды при установке: 0755;
- новые приватные файлы: 0600.

Маска 077 не ослабляется. Приватные файлы проверяются до открытия внешнего каталога. Ссылки, дополнительные жёсткие ссылки и небезопасные владельцы/права приводят к отказу. Для `/usr/local` и `/usr/local/bin` создаваемые каталоги и безопасные root-каталоги 0700 получают 0755. Пользовательские/Homebrew-каталоги не присваиваются root: установка на таком пути прекращается с ошибкой, а не меняет владельца чужих данных.

## Управление после установки

| Команда | Назначение |
| --- | --- |
| `vpn-bigsur status` | Состояние службы и маршрута; это не новая проверка интернета |
| `vpn-bigsur test` | Проверка DNS, HTTPS, маршрутов и выходного IP |
| `vpn-bigsur report` | Последний сохранённый отчёт |
| `vpn-bigsur off` | Остановка собственного VPN |
| `vpn-bigsur on` | Подключение VPN; уже активное соединение проверяется без принудительного пересоздания |

Справка: `vpn-bigsur --help`. Версия: `vpn-bigsur --version`. Эти две операции не требуют sudo; команды управления запрашивают административные права. Варианты с двумя дефисами, включая `--status`, также поддерживаются. `vpn-bigsur update` обновляет подписку серверов, не программу. Для обновления программы и пересоздания подключения используется постоянная команда выше.

## Проверки

Повторно выполнено **68/68 целевых offline-тестов, без пропусков**, в Linux с Python 3 и Bash среды проверки:

```sh
python3 -m unittest discover -s tests -p 'test_vpn_*.py' -v
```

В текущем наборе: 51 проверка прав/CLI из `tests/test_vpn_permissions_cli.py`, 12 проверок жизненного цикла setup, 3 проверки порядка/устранения дубликатов списка кандидатов и 2 проверки загрузчика из `tests/test_vpn_setup_reconnect.py`.

Проверки прав используют реальные временные каталоги и непривилегированные дочерние процессы. Проверки setup используют подмены сетевых операций и launchd: установка с нуля, обновление с подготовкой до остановки, повторное подключение актуальной версии, отказ при небезопасном пути/профиле, ошибки скачивания/остановки/исходного замера, откат новой сессии при ошибке или прерывании итоговой проверки, успешный результат с предупреждениями.

В `candidates` набор уже просмотренных идентификаторов представлен ограниченным списком вместо множества; порядок, устранение дубликатов и предел девяти кандидатов проверены отдельно. Протоколы, профиль, версия sing-box и механизмы TUN/DNS не обновляются этим изменением.

`bash -n vpn.sh` выполнен успешно. SHA-256 локального runtime соответствует загрузчику; Git blob локального runtime и загрузчика соответствует ответам GitHub при публикации.

Это не полный набор тестов репозитория и не PASS GitHub Actions. Проверенный предыдущий CI-запуск PR завершился failure до назначения runner: runner_id=0, список steps пуст. Успешных CI-проверок из этого результата не следует.

**Не проверено:** настоящая macOS Big Sur, штатные Python 2.7 и Bash 3.2, ACL macOS, установка на устройстве, реальный launchd, TUN, DNS и смена IP после обновления. Успешные offline-тесты не заменяют эти проверки.

## Внутреннее закрепление компонентов

Публичный адрес остаётся постоянным. Внутри загрузчика закреплён runtime:

```text
commit: d798e10400d56cc36f41155bc7b01f8727d4c10b
SHA-256: d7a59e0c4a1ff4316a67b9c705a6529afb1250a8873b18d3972efb16d3790d2d
Git blob: 0b5fb15e40bbd8bf68f67862baa4f53e7f7f31fb
```

Закрепление файла профиля сохранено. При публикации и обновлении не нужно передавать пользователю эти значения или просить вводить их вручную.

Требуется установленная macOS Big Sur 11.x Intel. Internet Recovery и другие версии ОС этой версией не поддерживаются. Старый блок chmod исправляет доступ к установленной 2.0.2 без переподключения, но не обновляет код; постоянная команда после публикации выполняет полноценную установку/обновление и пересоздание сессии.
