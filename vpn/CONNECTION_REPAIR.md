# Один запуск: выбор Xray или SOCKS5

Постоянная команда:

```sh
curl -fL https://raw.githubusercontent.com/pioner22/MacOS/main/vpn.sh | bash
```

## Исправление переключения — мастер 1.1

Предыдущий аварийный сценарий 1.0 для установленного VPN всегда вызывал восстановление SOCKS5. Он действительно обходил выбор Xray. Теперь `entry.sh` загружает проверенный `connection-menu.py` вместе с неизменённым `connection-repair.py`; оба файла повторно проверяются после повышения привилегий.

Для проверенной установленной версии 2.1.3 или 2.1.4 показывается меню:

```text
1 — Xray (VLESS / Trojan)
2 — SOCKS5 (проверить оба адреса)
0 — Отмена, оставить текущее подключение
```

Меню читает ответ из `/dev/tty`, а не из конвейера `curl | bash`. До выбора не выполняются остановка VPN, изменение каталога, сетевые пробы или обновление подписки. Отмена в меню и отсутствие ввода не меняют действующее подключение.

**Xray:** используется сохранённый каталог VLESS/Trojan, включая штатное обновление подписки внутри существующего runtime. Служба явно переключается, затем проверяются TUN/DNS/HTTPS/выходной IP и фактический тип конфигурации. После успеха режим сохраняется для `vpn-bigsur on`. Реквизиты SOCKS5 не удаляются. Если переключение не удалось, предпринимается проверяемый возврат к ранее работавшему режиму; результат всё равно FAILED, а возврат на SOCKS5 не выдаётся за успешный Xray. После отмены начатого переключения повторное подключение автоматически не запускается.

**SOCKS5:** сохранён прежний сценарий восстановления: сначала проверяется `87.251.86.229:45004`, затем `144.31.180.114:45004`. Авторизация берётся из локального профиля только для этих согласованных адресов и порта. Прямые HTTPS-проверки обходят локальный порт 17890; затем проверяется системный туннель. Подробности curl выводятся без локальных реквизитов. Чужой процесс на занятом порту не завершается.

Общая блокировка запрещает параллельное переключение. При установленном отдельном сервисном слое мастер отказывается запускаться, чтобы не конкурировать с контроллером. Без существующей установки остаётся прежний мастер первой установки.

## Границы

Это обновление запуска/переключения, НЕ установка нового runtime, фоновой службы или приложения. Номер `vpn-bigsur version` остаётся прежним. Локальная CLI 2.1.3 не получает новую команду wizard этим исправлением; для смены режима используется одна постоянная команда выше. Пароли и ядро не включаются в новые файлы.

Kill switch отсутствует: при переключении возможен прямой интернет. Доступность Xray и SOCKS5 зависит от фактической сети и проверяется на Mac; успешный локальный тест не доказывает доступность сервера.

## Проверка 7 ноября 2026

45 целевых тестов на Linux: выбор, отсутствие действий до подтверждения, Xray/SOCKS5 dispatch, проверка фактического протокола, сохранение свежей подписки, отмена, откат и защита доставки. Сеть, launchd, DNS и TUN моделируются; файловые операции, блокировка и исполнение проверяющего загрузчика с инертными файлами — реальные. Дополнительно проверен контракт каталога с исходниками runtime 2.1.3 и 2.1.4.

Все 8 целевых компилируемых мутаций обнаружены функциональными тестами. Успех нативной проверки на Big Sur, Python 2.7, запуска sing-box или подключения к реальным серверам не заявляется. Предыдущий SOCKS5 recovery и runtime не изменены.
