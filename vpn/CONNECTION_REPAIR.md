# Один запуск: проверка и восстановление SOCKS5

Постоянная команда:

```sh
curl -fL https://raw.githubusercontent.com/pioner22/MacOS/main/vpn.sh | bash
```

Для существующей проверенной установки BigSurVPN 2.1.3 или 2.1.4 на Big Sur Intel новый `entry.sh` запускает `connection-repair.py`. Вводить SOCKS5-реквизиты и диагностические команды не нужно; потребуется только системное подтверждение администратора. Без существующей установки сохраняется прежний мастер первой установки. `vpn/vpn.sh` оставлен прежним для этой совместимости и его регрессионных тестов.

Сначала проверяется `87.251.86.229:45004`, затем `144.31.180.114:45004`. Авторизация берётся из локального профиля только для этих согласованных адресов и порта. Прямые запросы curl обходят локальный порт 17890, проверяют TLS и ожидаемый ответ. Два независимых контрольных ресурса уменьшают зависимость от одного сайта. Затем выбранный адрес проверяется через существующий системный туннель. Старые проверки runtime, включая проверки GitHub и выходного IP, сохраняются.

При ошибке выводится подробность curl без локальных реквизитов. Диагностика занятого порта выводит команду/PID/UID, но не завершает чужой процесс. При отсутствии рабочего подключения сохраняются прежние настройки; для ранее запущенного VPN предпринимается проверяемая попытка восстановления. Отмена не запускает VPN заново. Отчёт сохраняется в существующем private/last-report.json и выводится по ходу работы; вручную собирать его командами не требуется.

Это изменение сценария подключения, НЕ обновление версии CLI или ядра. Фоновая служба, графическое приложение и автообновление не устанавливаются. При обнаруженном отдельном сервисном слое запуск блокируется во избежание конкуренции. Kill switch отсутствует: при проверке и переключении возможен прямой интернет. Доступность серверов проверяется на Mac пользователя, а не заявляется по результатам Linux-тестов.

Проверка разработчика: 43 теста обработки данных/состояний и 9 shell-тестов доставки выполнены на Linux; сеть, launchd, TUN и команды macOS моделируются. Дополнительно проходят 32 теста генератора корневых запускаторов. Это не нативная проверка Big Sur или реальных серверов.
