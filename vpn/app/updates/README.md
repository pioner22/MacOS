# Канал обновлений

`appcast.xml` появится здесь только после подготовки и проверки первого настоящего
подписанного выпуска приложения. Пустая или фиктивно подписанная лента не публикуется.
Отсутствие ленты не означает «установлена последняя версия»: Sparkle сообщает об ошибке
проверки, а тестовая сборка вообще не включает канал без ключа.

Для публикации сначала разместить неизменяемый ZIP в GitHub Release с тегом из
подготовленного `release.json`, затем перенести сюда уже подписанный `appcast.xml`
БЕЗ форматирования/изменения пробелов. После изменения XML нужна новая подпись.

Канал относится только к `ru.pioner22.BigSurVPN`, не к Electron-клиенту Yagodka и не
к `vpn.sh`. Приватных ключей, паролей SOCKS5 и профилей VPN здесь быть не должно.
