# BigSurVPN: служба контроля — 0.1.0-preview

Это экспериментальный сервисный слой поверх установленного BigSurVPN 2.1.4.
Это не стабильный выпуск, не собранное приложение из PR №19 и не обновление main.
На macOS Big Sur и штатном Python 2.7 этот код ещё не запускался. Не выдавать
переносимые тесты за испытание launchd, TUN, DNS, пользовательского окна или PKG.

## Реализовано в исходниках

- `supervisor.py`: последовательный контроллер, постоянное намерение on/off,
  общая блокировка с командами прежнего runtime, журнал переходов с ротацией.
- `macos_adapter.py`: реальные вызовы launchd и существующего проверяемого runtime,
  отдельный кандидат без системных маршрутов, проверка уже поднятого TUN.
- `service_policy.py`: интервал 2 секунды, 10 неудач подряд, циклический перебор
  сохранённых SOCKS5/VLESS/Trojan-профилей без предела кругов. Успех сбрасывает
  счётчик. Рабочий профиль не заменяется первым без причины.
- Добавляются оба согласованных SOCKS5-адреса: 144.31.180.114:45004 и
  87.251.86.229:45004. Авторизация берётся из локального профиля. Чужие реквизиты
  автоматически на эти адреса не переносятся. AmneziaWG не реализован.
- Два небольших HTTPS-запроса в общем двухсекундном бюджете вместо ICMP.
  Один корректный ответ HTTP 204 означает успех раунда. Транспорт явно привязан
  к TUN или кандидатному прокси. Подготовка кандидата, DNS-разрешение, проверка
  маршрутов и переключение имеют отдельные затраты времени; ровно 20 секунд
  реального времени до переключения не гарантируются.
- При отсутствии физического en*-соединения проверки серверов приостанавливаются.
  Это не полноценная диагностика провайдера и не поддержка всех bridge-интерфейсов.
- `probe_guard.py`: завершает временное ядро при закрытии канала контроллера.
- `user_agent.py`: отдельный непривилегированный агент Aqua показывает фиксированное
  модальное предупреждение после полного неудачного круга. При отсутствии сети
  предупреждение появляется после 20 секунд ожидания. Окно не блокирует контроллер.
  Внутри одного запуска агента повтор того же эпизода подавляется; после перезапуска
  агента такое окно может появиться снова. При выходе пользователя окна не показываются.
- `install_service.py`: отдельные LaunchDaemon контроллера и обновления и LaunchAgent
  предупреждений; сохранение исходной CLI-оболочки и отдельное удаление сервисного слоя.

Служба запускается после загрузки системы. Решение «Выкл.» записывается на диск:
перезапуск контроллера не должен включать VPN против этого решения. Подтверждение
«Выключено» выдаётся только после подтверждённой очистки. Внутренняя ошибка
адаптера приостанавливает автоматику; сетевой отказ продолжает перебор.

**Kill switch не реализован. Во время отказа и переключения возможен прямой интернет.**
Прежние ключи, подписка и конфигурация не включены в этот пакет. Каталог профилей
не переписывается при каждом переключении; фактическое подключение хранится отдельно.

## Автообновление: реализация и ограничения

Отдельное задание запускается при загрузке и затем каждые 21600 секунд — 6 часов.
Оно не исполняет shell-скрипты из main. `secure_update.py` проверяет отдельную
RSA-3072/4096/SHA-256 подпись манифеста с заранее установленным публичным ключом,
срок действия, канал stable, номер сборки, Big Sur/Intel, размер и хэш PKG,
Developer ID Installer ожидаемого издателя и решение Gatekeeper.

Загрузка не требует остановки VPN. **В preview установка разрешена только при
подтверждённо выключенном VPN**; иначе `DEFERRED_UNTIL_VPN_STOPPED`. Обновление
работающего соединения с автоматическим восстановлением ещё не реализовано.

Публичный ключ издателя, Apple Team ID, подписанный манифест и готовый PKG в этой
поставке отсутствуют. Результат — **NOT_CONFIGURED**, а не ложное «Обновлено».
Служба не доверяет ключам из профиля VPN или неподписанного удалённого JSON.
Закрытые ключи выпуска в чат или публичный репозиторий не помещать.

Последовательность: проверка версии → при необходимости проверенная установка →
запуск обновлённого updater → повторная проверка версии → обновление подписки.
Без подтверждения актуальности подписка не меняется. Без настроенной подписки
возвращается not_applicable. Если VPN выключен, подписка, требующая его транспорта,
может не обновиться; это не повод самостоятельно включать VPN после «Стоп».

Проверка установленной версии опирается на PKG receipt; перед стабильным выпуском
нужно дополнить и испытать подтверждение версии всех реально запущенных компонентов.
**Транзакционный откат не реализован:** частично применённый неудачный PKG может
потребовать ремонта. Код не объявляет такой отказ успешным и блокирует повтор той
же неудачной сборки. Пригодность PKG, его scripts и смена службы должны быть испытаны
на Mac до публикации подписанного канала. Сейчас готового безопасного автообновления
всей системы «под ключ» нет.

## Команды после установки сервисного слоя

```sh
vpn-bigsur on
vpn-bigsur off
vpn-bigsur service status
vpn-bigsur service pause
vpn-bigsur service resume
vpn-bigsur service logs
vpn-bigsur wizard
vpn-bigsur update
vpn-bigsur service remove
```

`pause` останавливает только автоматику и сохраняет текущий туннель. `off` прекращает
автоматику и отключает VPN. `on` подтверждает принятие запроса, не успешную связь.
`update` в preview возвращает NOT_CONFIGURED до настройки подписанного канала.
Без сервисного слоя установленная CLI сохраняет прежний смысл команды update.
Удаление сервисного слоя выключает VPN, восстанавливает старую оболочку и сохраняет
ядро/профили. Не запускать старый установщик поверх активного сервисного слоя.

## Только для отдельного испытания

Не ставить эту preview автоматически на рабочую машину. Для осознанного испытания
на Big Sur 11.x Intel с уже установленной проверяемой 2.1.4, из распакованной папки:

```sh
sudo /usr/bin/python -E -s -B ./install_service.py --development
```

Xcode, Homebrew и новый Python этот установщик не скачивает. Без явного флага
установка запрещена. Неизвестная версия runtime не подменяется. При успешной
регистрации контроллер начинает работать согласно сохранённому состоянию VPN;
это уже может привести к реальному переключению при последующих отказах.

## Проверки 5 ноября 2026 года

79/79 unittest прошли на Linux x86_64 / Python 3.13.5. Реальны файловые операции,
режимы доступа, межпроцессные блокировки, остановка дочерних процессов и криптография
OpenSSL. Вызовы Apple, сети и ядра в переносимых тестах заменены тестовыми двойниками.
12/12 целевых мутаций обнаружены; ошибок раннера и тайм-аутов в итоговом прогоне нет.
Это не показатель надёжности всего приложения и не нативное испытание.

Воспроизведение — только в изолированной Linux-среде с root для проверок владельцев:

```sh
python3 -B -m unittest discover -s tests -v
python3 -B tools/mutation_check.py
```

До стабильного выпуска: Big Sur/Python 2.7, запуск после перезагрузки, сон/пробуждение,
потеря Wi-Fi, отказ каждого реального сервера, Stop во время переключения, окно Aqua,
конфликты ручных команд, журналирование, удаление/повторная установка, подписанное
обновление N→N+1, восстановление после прерванной установки и подтверждение версий.
